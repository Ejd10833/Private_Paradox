# Private_Paradox
Private Paradox is a collaborative game development project created for CSC 281: Introduction to Game Design at North Carolina State University.

Developed using GameMaker, Private Paradox is a top-down action game featuring player combat, enemy encounters, and boss battles.

This repository hosts the browser-playable HTML5 build.

**Development Team:** ejd10833, joshgarrido04-dot, and smmbye.

**Original Source:** Private GameMaker team repository.

This game was developed as an educational project. All team contributions are acknowledged.
